# 🤝 Участие в разработке

Ошибки и предложения можно описывать на русском или английском в [Issues](https://github.com/shirstylee/Emoji-Sticker-Info-Bot/issues). Для уязвимостей используйте [SECURITY.md](SECURITY.md).

## Локальная разработка

1. Сделайте fork, клонируйте его и создайте отдельную ветку.
2. На Windows выполните `.\setup.ps1`. На Linux/macOS создайте `.venv`, активируйте её и выполните `python -m pip install -e ".[dev]"`.
3. Для ручной проверки используйте собственного тестового бота и локальный `.env`.
4. Перед pull request запустите:

```powershell
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe scripts/check_publication.py --history
```

Тесты не требуют токена и не отправляют запросы в Telegram. В Linux/macOS используйте `python` из активированной `.venv`.

## Изменения

- Один pull request должен решать одну понятную задачу.
- Обновляйте русский и английский тексты вместе.
- Добавляйте тесты для нового поведения и исправленных ошибок.
- Не включайте `.env`, виртуальное окружение, базу пользователей и личные логи.
- Опишите, что изменилось и как это проверено.
